# 设计稿分析（product · 取材）

根据 MasterGo 导出的设计稿数据（选中图层 + 文件变量）写一份**设计分析**正文，交给产品和开发使用。

需求原文：

{requirement}

设计稿数据（JSON，可能被截断）：

```json
{design}
```

## 正文固定以下小节

1. **概览**：设计稿是什么页面 / 状态
2. **布局与区域**：区域划分，每个区域放了什么（引用图层名）
3. **组件清单**：按区域列出组件及其状态
4. **文案**：图层里的文字原样列出
5. **视觉样式**：颜色、字号、圆角、间距，优先引用设计变量名
6. **交互推测**：能从图层命名 / 结构合理推断的交互，注明依据
7. **与需求的对应**：需求里的每一点在设计稿里对应哪里；没有的写「设计稿中未体现」
8. **不确定的地方**：数据里看不出来的，没有就写「无」

只输出 Markdown 正文：不要 front-matter，不要 yaml 代码块（machine 块由流水线生成），不要写占位词，不要修改文件。
